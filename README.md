# EDA – Retail Business Analysis Case Study

## 📌 Project Overview

Exploratory Data Analysis (EDA) on retail business data to uncover
sales trends, customer purchasing patterns, product performance,
and actionable business insights.

## 🎯 Objectives

- Analyze overall sales performance
- Identify sales trends and patterns
- Understand customer purchasing behaviour
- Analyze product/category performance
- Identify high-performing and low-performing segments
- Generate actionable business insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub

### 1. Data Understanding

- Duplicate records

### 2. Data Cleaning
- Missing-value handling
- Duplicate removal
- Data-type corrections
- Data consistency checks

### 3. Exploratory Data Analysis
- Sales analysis
- Customer behaviour analysis
- Product/category analysis
- Time-based sales trends
- Distribution analysis

### 4. Visualization

Created visualizations to understand:

- Sales trends
- Customer purchasing patterns
- Product performance
- Category performance
- Business trends

## 📊 Key Insights

The analysis identifies important patterns in retail sales,
customer behaviour, and product performance that can support
data-driven business decisions.

## 💡 Business Recommendations

The findings can be used to:

- Improve sales strategies
- Identify high-performing products
- Understand customer purchasing behaviour
- Optimize product/category performance
- Support data-driven decision making
